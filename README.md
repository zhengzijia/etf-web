# 宽基ETF市值 / 指数流通市值

展示 A 股主要宽基指数（沪深300 / 中证500 / 上证50 / 创业板指 / 科创50）的
**前10大ETF市值 占 指数流通市值 比例**，反映被动投资（指数化）的渗透程度。

## 在线查看

GitHub Pages 地址：`https://<用户名>.github.io/etf-web/`

每张图：
- 左轴（蓝线）：前10大ETF市值 / 指数流通市值（%）
- 右轴（黄线）：指数点位

数据由 GitHub Actions 每个交易日收盘后自动更新（增量拉取）。

## 本地运行

```bash
pip install pandas numpy requests openpyxl
python build_data.py   # 生成 index.html（自包含，双击即开）
```

## 数据口径

- ETF市值 = 份额（沪深交易所日频）× 价格（新浪K线，宽基ETF溢价<0.5%≈净值）
- 指数流通市值 = 东财当前流通市值 × 指数点位比例（历史值估算）
